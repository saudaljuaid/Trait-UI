trait.svg is this project's own mark, drawn to the proportions of the
logo the project was given.  No part of it is taken from another icon
set, and it is the panel's menu button - which is where LXDE puts its own
lxde-icon.png.  That file is vendored in ../icons/lxpanel/ as well,
because the panel's geometry was measured off it.

Both SVGs carry their fill and stroke on the ROOT <svg> element rather
than on a <g>.  That is a portability constraint, not a style: Phipia
OS's tools/svgpath.py inherits paint from the root or from each shape and
from nothing in between, so paint on a group rasterizes to an empty icon
while still rendering correctly in a browser.  See the integration
section of the README.

files.svg is this project's own too: the Files application's mark, drawn
in the same geometry as trait.svg - the same shear, the same rounding -
as a drawer with two sheets standing in it.  Grey rather than a bright
folder, because the desktop it sits on is the grey Debian one and a
saturated mark would be the only loud thing on the bar.  It is NOT
nuoveXT2's file-manager.png, which is still vendored beside it and is
what the panel drew before this.

logout-banner.png WAS here, at lxsession-logout's own 352x125, and is
gone with the dialog it sat on.  A page has no session to end: the dialog
closed every window and called that logging out, which is a control doing
something other than what it is named, so the whole thing was removed
rather than kept for its picture.  tools/banner.html and
tools/make-banner.py went with it.
