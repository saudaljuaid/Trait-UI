wallpaper.png is this project's own art.

It is not a photograph and not taken from anybody's wallpaper set: a
cool grey-blue ground (#C4CBD3), the project's mark and wordmark at the
upper left, and along the foot a run of thin-line towers that climb
towards the right.  Each tower is a scatter of straight chords
drawn inside a narrowing silhouette, so the scribble stays in the
shape rather than forming a cloud.

The scatter is SEEDED - mulberry32 at 20260914 - so the file is the same
every time it is rendered rather than a lucky throw:

    python3 tools/make-wallpaper.py assets/wallpaper/wallpaper.png 1920 1080

which draws tools/wallpaper.html in the same browser the screenshots come
from.  Change the seed and you get a different set of towers; change
nothing and you get this file back.

The wordmark is set in DejaVu Sans Bold, which is the font this container
has and is itself freely licensed (Bitstream Vera / DejaVu licence).

The desktop no longer draws this.  The root window is glxgears now, from
geometry, and there is no image loader left to put a PNG behind it.  The
file stays because the Trait palette in src/theme.c was sampled out of
it - the #212121 ground is read from its corner - and a palette whose
source has been deleted is a palette somebody chose.
